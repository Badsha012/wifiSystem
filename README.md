# Wi‑Fi নিরাপত্তা ল্যাব

একটি ছোট, অফলাইন শিক্ষামূলক ওয়েব অ্যাপ—কাল্পনিক রাউটারের সেটিংস বেছে নিয়ে প্রাথমিক Wi‑Fi নিরাপত্তা অভ্যাস সম্পর্কে ধারণা নিন। সবকিছু আপনার ব্রাউজারেই চলে; কোনো বাস্তব নেটওয়ার্কে সংযোগ বা স্ক্যান করা হয় না।

## ফিচার

- WPA3, WPA2-AES, এবং WEP/খোলা এনক্রিপশন বিকল্প
- WPS, অ্যাডমিন পাসওয়ার্ড, ফার্মওয়্যার আপডেট, এবং গেস্ট নেটওয়ার্ক সেটিংস
- ১০০ পয়েন্টের শিক্ষামূলক স্কোর ও প্রতিটি সেটিংসের জন্য পরামর্শ
- স্কোর অনুযায়ী রঙিন ফলাফল এবং অ্যাক্সেসিবল প্রগ্রেস বার
- মোবাইল ও ডেস্কটপে ব্যবহারযোগ্য রেসপনসিভ ডিজাইন
- কোনো ফ্রেমওয়ার্ক, বিল্ড ধাপ, বা তৃতীয়-পক্ষের নির্ভরতা নেই

## চালানোর নিয়ম

1. এই রিপোজিটরি ডাউনলোড বা ক্লোন করুন।
2. [index.html](./index.html) ফাইলটি যেকোনো আধুনিক ওয়েব ব্রাউজারে খুলুন।
3. সেটিংস নির্বাচন করে **নিরাপত্তা মূল্যায়ন করুন** বোতামে চাপ দিন।

অ্যাপটি সরাসরি ফাইল থেকে চালানো যায়; লোকাল সার্ভার দরকার নেই।

## স্কোরিং

| বিষয় | সর্বোচ্চ পয়েন্ট |
| --- | ---: |
| WPA3 এনক্রিপশন | ৩০ |
| WPA2-AES এনক্রিপশন | ২৪ |
| WPS বন্ধ | ১৫ |
| ডিফল্ট অ্যাডমিন পাসওয়ার্ড পরিবর্তন | ২০ |
| ফার্মওয়্যার আপডেট রাখা | ২০ |
| গেস্ট নেটওয়ার্ক আলাদা রাখা | ১৫ |

ফলাফলের স্তর:

- **৮০–১০০:** ভালো নিরাপত্তা অভ্যাস
- **৫০–৭৯:** আরও উন্নতির সুযোগ আছে
- **০–৪৯:** কয়েকটি গুরুত্বপূর্ণ পরিবর্তন দরকার

এটি কেবল শেখার জন্য একটি সরলীকৃত হিসাব—বাস্তব রাউটারের নিরাপত্তা অডিট বা নিশ্চয়তা নয়।

## গোপনীয়তা ও নিরাপদ ব্যবহার

- অ্যাপটি কোনো Wi‑Fi নেটওয়ার্ক খোঁজে, স্ক্যান করে, বা তাতে যুক্ত হয় না।
- পাসওয়ার্ড বা ব্যক্তিগত তথ্য চায় না।
- কোনো তথ্য সার্ভারে পাঠায় বা সংরক্ষণ করে না।
- বাস্তব রাউটারের গোপন তথ্য এখানে প্রবেশ করাবেন না।

## প্রযুক্তি

সাধারণ HTML, CSS, এবং JavaScript। অ্যাপের যুক্তি ও স্টাইল [index.html](./index.html)-এ রাখা হয়েছে।
